# Little Loom — Boutique Website Concepts

Three independent website concepts for a handmade-gifts boutique, designed to explore different visual identities, responsive layouts, and interactive shopping experiences.

## Overview

**Little Loom** is a front-end website concept for a boutique specialising in handmade gifts, crochet creations, personalised products, and thoughtful gift boxes.

This project contains three distinct design directions. Each concept has its own HTML, CSS, and JavaScript files, allowing the designs to be viewed and tested independently.

The goal was to explore how a single boutique brand could communicate its personality through different design styles while keeping the experience attractive, accessible, and easy to navigate.

## Features

- **Three independent designs:** Compare three different visual approaches for the same boutique brand.
- **Responsive layouts:** Adapt the page layout for desktop and mobile-sized screens.
- **Product filtering:** Browse products by category where implemented.
- **Product interactions:** Interactive favourite buttons and product enquiry shortcuts where implemented.
- **Mobile navigation:** A collapsible navigation menu on supported designs.
- **Enquiry preview:** Review the details of a sample gift enquiry before copying it.
- **Consistent project organisation:** Separate HTML, CSS, and JavaScript files for each concept.
- **CSS illustrations:** Concept 3 includes decorative product illustrations made with CSS.

## Technology Stack

- **HTML5** — Page structure and content.
- **CSS3** — Layout, styling, responsive behaviour, and visual details.
- **Vanilla JavaScript** — Interactive controls and client-side behaviour.
- **Google Fonts** — Typography for the selected design directions.
- **Git and GitHub** — Version control and project hosting.

No front-end framework is required to run these static website concepts.

## Run Locally

1. Download or clone this repository.
2. Open the project folder in VSCodium or another code editor.
3. Open the `index.html` file inside the concept you want to explore.
4. Open that file in a modern web browser.

You can also use a local development server, such as the Live Server extension in VSCodium, to preview the pages.

Each concept is independent. Open its own `index.html` file rather than the HTML files inside `backup-root-files`.

## Interactive Features

Depending on the selected concept, you can explore category filters, product controls, navigation, and enquiry interactions.

The enquiry experience is a **front-end demonstration only**. It prepares a preview of the information entered by the visitor. It does not send an email, store customer information on a server, or submit an order to a real business.

Any displayed product prices are illustrative and should not be treated as confirmed commercial prices.

## Current Scope and Future Improvements

This project focuses on front-end design and interaction. It does not currently provide a production backend, payment processing, customer accounts, or a live order-management system.

Potential next steps include:

- Connecting a real enquiry form to a backend or form service.
- Adding product photography and verified product details.
- Improving accessibility through keyboard and screen-reader testing.
- Testing responsive layouts across more devices and browsers.
- Adding automated tests and performance checks.
- Selecting one design direction for further development.

## Project Purpose

Little Loom is a practical exploration of front-end development, visual design, responsive interfaces, and interactive website behaviour.

The three concepts make it possible to compare different design decisions before choosing a direction for a more complete boutique website.
